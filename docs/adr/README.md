# リポジトリ内の決定事項をまとめる (Architecture Decision Records)

## ADR の内容

### ファイル名
`YYYYMMDD_<title>.md`

### Status
この判断が今どの段階かを表す。
- `Proposed`: まだ決めていない、またはレビュー中
- `Accepted`: 採用して実装に入った、または入る前提
- `Rejected`: 検討したが不採用
- `Deprecated`: 以前は正しかったが、もう推奨しない状態
- `Superseded by ADR-<ADR_NUMBER>`: 別の判断に置き換わった状態

### Context
決定が必要になった背景

### Decision 
何を決めたか

### Consequences
影響とトレードオフ
