# ADR 0010: 電話機との同期と Wi-Fi の設定を Bluetooth LE で行う

## Status

Accepted

## Context

ADR 0003 は 2 つのことを決めずに残した。1 つは電話機とラズパイのつなぎ方で、もう 1 つは、アプリと電話機を同期し、電話機を見守る方の家の Wi-Fi につなぐ方法である。

ADR 0003 は電話機について 2 つの案を挙げた。案 A は専用の電話機で、受話器を USB オーディオでラズパイにつなぎ、フックとボタンを GPIO で読む。案 B は市販のアナログ電話機を、アナログ電話アダプタ(ATA)でつなぐ。有力なのは案 A だった。

モックの同期の画面(L3〜L5)は、次の流れを描いている。家族が電話機のボタンを押すとランプが光り、家族がアプリの「同期開始」を押す。この流れは、スマートフォンが近くの電話機を見つける形に合っている。モックには Wi-Fi を選ぶ画面がない。L5 は電話番号を出し、L4 は電話線がつながっているかを尋ねる。

ほかに次の案があった。

- 電話機を送る前に Wi-Fi か LTE を設定しておき、電話機に書いたコードを入れて同期する。見守る方の家で Wi-Fi を設定する手間はないが、流れがモックと合わず、LTE には月ごとの費用がかかる。
- 電話機に貼った QR コードを読んで同期する。この案でも、電話機をネットにつなぐ方法は別に要る。

## Decision

- 電話機は案 A にする。電話線も電話番号も持たない。
- アプリは Bluetooth LE で電話機と同期する。電話機のボタンを押すとランプが光り、ランプが光っている間は Bluetooth LE で電話機を見つけられる。
- 同じ流れの中で、アプリは Bluetooth LE で、見守る方の家の Wi-Fi のネットワークとパスワードを電話機に渡す。
- アプリはまず、ログインした家族として、1 回だけ使える同期のトークンをバックエンドから受け取る。このトークンを Wi-Fi の設定と一緒に電話機に渡す。電話機は Wi-Fi につないでトークンをバックエンドに送り、バックエンドが電話機と見守る方を結び付ける。
- 見守る方 1 人に電話機は 1 台である。見守る方の設定(08)から同期し直すと、前の電話機との結び付きを置き換える。
- L5 は電話番号の代わりに電話機の名前を出す。L4 は電話線がつながっているかの代わりに、スマートフォンが電話機の近くにあるかを尋ねる。L4 と L5 の変更と、Wi-Fi のネットワークを選ぶ画面は、モックを作った方に頼む。
- モックのとおり、新規登録では同期を済ませてから見守る方を登録する。
- 同期を作るまでは、電話機のプログラムを起動するときに見守る方の ID を渡す。

## Consequences

### Pros

- 流れがモックの同期の画面と合う。ボタンを押し、ランプが光るのを見て、「同期開始」を押す。
- コードを入れる手間がなく、電話機に LTE の契約も要らない。
- 家族はふだん使うスマートフォンで、その場で Wi-Fi を設定できる。
- 電話機がどの見守る方のものかは、ログインした家族にバックエンドが渡したトークンを通してしか決まらない。

### Cons

- 同期するには、家族が見守る方の家で電話機の近くにいる必要がある。
- Wi-Fi のない家では電話機を使えない。
- ラズパイには BlueZ が、アプリには Bluetooth LE のライブラリと、iOS と Android の Bluetooth の許可が要る。
- Wi-Fi のパスワードを Bluetooth LE で送るので、接続を暗号化する必要がある。
- 同期を作る前に、モックに Wi-Fi の画面と、L4 と L5 の変更が要る。
