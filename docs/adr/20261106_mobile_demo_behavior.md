# ADR 0002: モバイルアプリのデモの動き

## Status

Accepted

## Context

手順 5 から、通話記録、AIに伝える、予約の画面を作る。
`backend/` と `device/` はまだ空なので、通話と AI の案は実データで動かせない。
モックは画面の静止画で、通話が終わる動きや不在の表示に切り替わる動きは描かれていない。
説明文と画面が違うところもあり、07b の説明文には「次の行動を3つ示します」とあるが、画面のボタンは 1 つである。

## Decision

- 手順 5 以降は、モックに合わせて作り、モックにない動きは足さない。
- 通話は 01 の「通話」を押すと通話中になる。終わる動きはモックにないので、自動では終わらない。
- 不在の表示は `--dart-define=HOME_STATE=missedCall` で確かめる。モックにない切り替えの UI は足さない。
- AI の言い方の案はモックの固定の文を出す。Gemini との接続はバックエンドと一緒に行う。
- ホームの「通話」の文言はモックのままとする。押すと 01 を開く。
- 07b のボタンはモックの画面どおり 1 つとする。
- 設計のない「なおす」「まとめの間違いを直す」「予約の詳細」は「準備中です」と表示する。

## Consequences

### Pros

- 作るものに迷ったときは、モックの画面を見れば決められる。
- バックエンドがなくても、デモの流れを同じ内容で繰り返せる。

### Cons

- デモの途中で通話中を終えられない。通常の表示に戻すには、アプリを起動し直す。
- 不在の表示はアプリの画面から開けないので、確かめるときはビルドし直す。
- AI の言い方の案は、入力した内容によらず同じ文になる。
- ホームの基準日時は状態ごとに変わる。ADR 0001 の 10:24 は通常の状態の値で、通話中は 10:27、不在は 9:31 になる。不在の表示で「もう一度電話する」を押すと、ヘッダーの時刻は 9:31 から 10:27 に変わる。
