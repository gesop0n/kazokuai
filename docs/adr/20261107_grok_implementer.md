# ADR 0007: 実装役を Grok だけにする

## Status

Accepted

## Context

ADR 0004 では、実装役を Claude Code と Grok にすると決めた。最初のチケットは Claude Code に渡し、2 つ目のチケットからは同時に 2 つまで、Claude Code と Grok に 1 つずつ渡していた。
これまでに、Claude Code が #19 と #27 を、Grok が #20 を実装した。これを決めたときは、Claude Code が #31 を、Grok が #30 を実装していた。
人は、これからはすべてのチケットを Grok が実装すると決めた。#31 は作業がだいぶ進んでいたので、Claude Code のままにする。
この ADR は ADR 0004 のうち、実装役を決めた部分を置き換える。レビュー役を決めた部分は、ADR 0006 ですでに置き換えている。

## Decision

- すべてのチケットを Grok が実装する。
- 同時に進めるチケットは 2 つまでで、チケットごとに、自分のワークツリーで別の Grok が動く。ADR 0004 で決めたとおり、開いているブロッカーがないチケットだけを進める。
- ADR 0004 で決めたとおり、Grok は `git push` と `gh` を止める `--deny` のルールを付けて起動する。
- ADR 0006 で決めたとおり、Claude Code は指揮役のまま、Codex はただ 1 人のレビュー役のままにする。

## Consequences

### Pros

- 実装役への指示と設定は、1 つのエージェントに合わせればよい。
- 指揮役がどのチケットをどのエージェントに渡すかを選ばなくてよい。

### Cons

- 似たチケットで Claude Code と Grok を比べることは、もうしない。
- すべての実装が Grok を使えることに頼る。
- #20 では Grok が約 29 分、それより大きい #19 と #27 では Claude Code が約 16 分と約 18 分かかった。3 つのチケットでは公平に比べられないが、チケットに時間がかかるようになるかもしれない。
