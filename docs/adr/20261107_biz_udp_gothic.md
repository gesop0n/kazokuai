# ADR 0008: アプリのフォントを BIZ UDPゴシックだけにする

## Status

Accepted

## Context

ADR 0001 では圧縮前で 23.91MB の 7 ファイルのフォントを同梱すると決めた。Zen Maru Gothic の 400、500、700、900、Shippori Mincho の 500、DM Mono の 400 と 500 である。
#37 でマージした最新のモックは、すべての文字に BIZ UDPゴシックだけを使う。Shippori Mincho と DM Mono を使っていた文字も同じである。BIZ UDPゴシックの太さは 400 と 700 の 2 つだけで、モックもこの 2 つだけを読み込む。そのためブラウザでは、モックで太さ 500 を指定した文字は 400 で、900 を指定した文字は 700 で表示される。
BIZ UDPゴシックは置き換える前のフォントと同じく、SIL Open Font License 1.1 で公開されている。
この ADR は ADR 0001 のうち、同梱するフォントの一覧を置き換える。ADR 0001 のほかの決定は変えない。`google_fonts` を使わずにフォントを同梱すること、フォントのライセンスの本文を同梱して `LicenseRegistry` に登録することは、そのままである。

## Decision

- アプリには BIZ UDPゴシックの Regular(400)と Bold(700)の 2 ファイルを同梱する。合わせて圧縮前で 9.31MB である。Zen Maru Gothic、Shippori Mincho、DM Mono は外す。
- すべての文字のスタイルに BIZ UDPゴシックを使う。
- モックで太さ 500 を指定したところはアプリでは 400 に、900 を指定したところは 700 にする。モックで見える太さである。
- 同梱するライセンスの本文は、BIZ UDPゴシックのものにする。

## Consequences

### Pros

- アプリに、モックと同じフォントが出る。
- フォントのファイルが 23.91MB から 9.31MB に減る。

### Cons

- 太さが 2 つだけなので、アプリでは 400 と 500、700 と 900 を区別しなくなる。
- 文字の幅を測るテストは最新のモックに対して測り直す必要がある。
- BIZ UDPゴシックにない太さをモックが使うと、アプリはそれに合わせられない。
