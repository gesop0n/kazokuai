ADR 0003 · ADR 0011 · ADR 0014 · 2026-11-10

かぞくAI の構成

いま作ってあるものだけを描く。左の見守る方の声は、電話機の Raspberry Pi から Gemini Live API へ届き、右の家族はアプリで電話の記録を見る。Cloud Run は ADR 0011 のとおり 1 つのインスタンスで動き、予約の時刻は Cloud Tasks が知らせる。家族はブラウザでは Firebase Hosting の Web 版を開いて /api/** から、iOS のアプリでは直接 Cloud Run を呼ぶ。公開は GitHub Actions から手で行う。
