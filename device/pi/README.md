# 電話機の配線

Raspberry Pi 4 Model B に Raspberry Pi OS Lite（64 ビット）を入れる。受話器のマイクと受話口は、1 つの USB オーディオのアダプターにつなぐ。フック、呼び出し音、キーパッドは GPIO である。ランプは付いていない。

キーパッドの読み取りは、あとの ticket で足す。呼び出し音は GPIO を入れたり切ったりして、本体のスピーカーを鳴らす。ランプはログだけを書く。

## 確認

電話機の上で、部品を 1 つずつ確かめる。音の出る確認は、受話器を耳から離してから始める。終わるまで続くものは Ctrl+C で止める。

| コマンド | 動作 |
|---|---|
| `device check devices` | 音声の機器の名前を並べる |
| `device check speaker` | 受話器で 1 秒の音を鳴らす |
| `device check mic` | 5 秒録って、受話器から流す |
| `device check hook` | 受話器が上がっているか、置かれているかを出す |
| `device check ringer` | 止めるまで、本体のスピーカーを鳴らす |

`devices` で見た名前の、他の機器と重ならない一部を `KAZOKUAI_AUDIO_DEVICE` に入れる。番号は再起動や接続の順で変わるので、名前で選ぶ。

## 設定

systemd が読む `/etc/kazokuai/device.env` に書く。空の項目は次の既定になる。

| 変数 | 既定 | 意味 |
|---|---|---|
| `KAZOKUAI_AUDIO_DEVICE` | 空 | USB アダプターの名前の一部。音声を開くときは要る |
| `KAZOKUAI_MIC_CHANNEL` | `0` | マイクのチャンネル。最初が 0 |
| `KAZOKUAI_SPEAKER_GAIN` | `0.15` | スピーカーの音に掛ける倍率。0 より大きく 4 以下 |
| `KAZOKUAI_SPEAKER_LIMIT` | `0.1` | フルスケールに対する上限。0 より大きく 1 以下 |
| `KAZOKUAI_GPIO_CHIP` | `gpiochip0` | GPIO のチップ |
| `KAZOKUAI_HOOK_GPIO` | `5` | フックの BCM 番号 |
| `KAZOKUAI_RINGER_GPIO` | `18` | 呼び出し音の BCM 番号 |
| `KAZOKUAI_LIFTED_WHEN_CLOSED` | `true` | 上げると接点が閉じるなら true、開くなら false |
| `KAZOKUAI_HOOK_DEBOUNCE` | `50ms` | フックが安定したとみなす時間 |

音は倍率を掛けたあと、上限を超えた部分だけを切る。この上限は耳元の音圧を保証しない。まず既定のまま、受話器を耳から離して確かめる。

`tel-base` の倍率 0.5 は、音全体を上限まで縮めるときの値である。こちらは掛けてから切るので、既定は 0.15 にしてある。

## 配線

番号は BCM である。

| 用途 | BCM 番号 | 物理ピン |
|---|---|---|
| キーの行 R1 / R2 / R3 / R4 | 17 / 27 / 22 / 23 | 11 / 13 / 15 / 16 |
| キーの列 C1 / C2 / C3 | 24 / 25 / 4 | 18 / 22 / 7 |
| 本体の呼び出し音 | 18 | 12 |
| 受話器のスイッチ | 5 | 29 |
| スイッチのもう片側 | GND | 30 |

キーの並びの既定は、上の行から `1 2 3`、`4 5 6`、`7 8 9`、`* 0 #` である。5 以外は実機で確かめてから使う。C4 や VSS など、表に無い端子はつながない。

受話器のスピーカーとマイクは、動作を確かめた USB の配線のまま使う。

## 安全

受話器のスイッチは、元の電話回路から電気的に切り離した無電圧の接点にする。切替接点なら、使わない側も含めて接点の組を全部切り離す。GPIO に電話回線や元の基板の電圧を加えない。

上げると接点が閉じるかは、`device check hook` で確かめる。違うときは `KAZOKUAI_LIFTED_WHEN_CLOSED` を変える。

呼び出し音は PAM8012（入力コンデンサーが入ったモジュール）を通して、本体の 8Ω スピーカーを鳴らす。GPIO18 から 10kΩ を経て分岐し、分岐から IN+ へ、分岐から 1kΩ を経て GND へつなぐ。V+ は 5V。GND と IN− は Pi の GND。SPK+ と SPK− は本体のスピーカーだけにつなぎ、SPK− を GND や USB の音声端子につなげない。配線を変えるときは Pi の電源を切る。

同じ GPIO を、同時に 2 つのプログラムで使わない。
